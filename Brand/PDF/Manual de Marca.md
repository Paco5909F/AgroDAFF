# AgroDAFF - Manual de Identidad Visual

Este documento establece las pautas maestras para la identidad visual de AgroDAFF. Está diseñado para garantizar coherencia en todas las plataformas: Web, SaaS, Mobile App y material impreso/PDF.

## 1. El Concepto
**"AgroDAFF: Innovación y Precisión en la Gestión Agrícola"**
El logotipo y el isotipo no son simples adornos; representan la solidez de una empresa AgTech seria. El isotipo (la "D" construida con espacio negativo y surcos sutiles) evita los clichés tradicionales del campo (tractores, soles, espigas) y abraza una estética vectorizada, flat y minimalista propia de gigantes como Stripe, Vercel o Notion.

## 2. Archivos Maestros

La carpeta `Brand/` contiene la única fuente de la verdad para la imagen de AgroDAFF:

### A. Isotipo (La "D" Pura)
- **Uso Obligatorio:** Aplicaciones móviles (Android/iOS), Favicons, Avatares, Loaders, Navbar colapsado.
- **Ruta:** `Brand/PNG/Isotipo.png`

### B. Logo Horizontal (Isotipo + Texto)
- **Uso Obligatorio:** Cabeceras de sitios web (Landing page), documentos oficiales, facturas, cartas de porte y PDFs.
- **Ruta:** `Brand/PNG/AgroDAFF-Horizontal.png`

### C. Modos Oscuros
- Para fondos muy oscuros, utilizar las variantes "White" que garantizan contraste y legibilidad impecable.

## 3. Tipografía y Estilos
- **Ausencia de efectos:** Queda terminantemente prohibido el uso de sombras proyectadas (drop shadows), brillos, biselados (bevels) o efectos 3D en el logo. El diseño es estrictamente FLAT.
- **Escalabilidad:** El isotipo está diseñado para ser legible incluso a tamaños de `16x16 px`.

## 4. Ecosistema de Favicons & App Icons
El ecosistema completo está cubierto en las carpetas respectivas:
- `Brand/Favicons/`: Maneja las pestañas de navegadores web de escritorio.
- `Brand/App/`: Aloja los iconos de alta resolución (`192px`, `512px`, `180px` Apple Touch) necesarios para PWAs (Progressive Web Apps) y tiendas de aplicaciones.

## 5. Colores
*(Ver archivo `Colores.txt` adjunto para los códigos HEX precisos de la interfaz).*
- El balance debe ser predominantemente **Azul Oscuro** y **Blanco**, utilizando el **Verde** como color de acento para la atención principal (Call to Action).
